## Cách chạy / deploy (QUAN TRỌNG — không rebuild Docker image)

```bash
# Backend: build jar rồi copy vào container đang chạy
cd backend && mvn package -q -DskipTests
docker cp app/target/app-1.0.0-SNAPSHOT.jar hrm-backend:/app/app.jar
docker restart hrm-backend

# Frontend: build rồi chạy script deploy
cd frontend && npm run build
cd .. && .\deploy-frontend.ps1
```

Lý do: `docker compose build` tốn 20-30GB disk mỗi vài lần. Xem chi tiết trong memory `feedback-deploy-workflow`.

### Sửa lỗi quan trọng
- **File view AccessDenied**: `/files/view` dùng `StreamingResponseBody` (async, mất SecurityContext
  do STATELESS) → đổi sang `ResponseEntity<byte[]>` đồng bộ
- **Ảnh chữ ký/avatar vỡ**: `<img>` không gửi được Bearer token → tạo component `AuthImage`
  (fetch kèm token → blob URL)
- **Nhắc chấm công 7:45 bị bỏ lỡ**: `@Scheduled` chỉ chạy nếu backend sống đúng giờ →
  thêm chạy bù `@EventListener(ApplicationReadyEvent)` + guard chống gửi trùng theo ngày
- **DEPT_HEAD không thấy menu**: backend gán role `DEPT_HEAD` nhưng sidebar chỉ check
  `DEPARTMENT_MANAGER` → thêm cả 2 tên (là tương đương)
- **Modal không phủ header** (lỗi hệ thống): mọi modal render trong `<main>` nên backdrop
  không phủ header → tạo `ModalPortal` (createPortal → document.body), áp cho tất cả modal
- **pgAdmin crash-loop**: email `.local` bị validator từ chối → đổi `dba@bvnghean.vn`
- **Rewrite thiếu**: `next.config.mjs` thiếu `onboarding` + `audit-log` (2 trang trả 404)

- **MinIO** phải chạy thì upload/xem file mới hoạt động; nếu Exited → `docker start hrm-minio`
